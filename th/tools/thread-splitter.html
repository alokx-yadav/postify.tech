เครื่องมือฟรี

เครื่องมือแบ่งเธรดสำหรับ X และ Threads

วางเนื้อหาที่ยาวเกินไปสำหรับหนึ่งโพสต์ แล้วรับกลับมาเป็นเธรดที่มีลำดับเลข แบ่งตามขอบเขตประโยค พอดีกับ 280 ตัวอักษรที่ X อนุญาตหรือ 500 ตัวอักษรบน Threads

อัปเดตล่าสุด: 2026-08-03

การแบ่งร่างข้อความยาวด้วยมือเป็นงานประเภทที่ดูเหมือนใช้เวลาสองนาทีแต่กลับกินเวลาไปยี่สิบนาที คุณนับไปจนถึง 280 แล้วมาหยุดกลางประโยค ต้องย้ายจุดตัด และตอนนี้ตัวเลขลำดับในเธรดทั้งหมดก็ผิดเพราะคุณเพิ่งเพิ่มโพสต์เข้าไปตรงกลาง

เครื่องมือแบ่งเธรดนี้คำนวณแทนคุณ มันอ่านข้อความของคุณเป็นย่อหน้าและประโยคแทนที่จะเป็นสายอักขระ จัดเรียงประโยคที่สมบูรณ์ให้ได้มากที่สุดในแต่ละโพสต์เท่าที่จะพอดี และจะตัดกลางประโยคก็ต่อเมื่อประโยคนั้นยาวกว่าขีดจำกัดจริง ๆ เท่านั้น การใส่ลำดับเลขจะทำเป็นขั้นตอนสุดท้ายและถูกนับรวมในงบตัวอักษรเดียวกับตัวข้อความ ซึ่งเป็นจุดที่การแบ่งด้วยมือส่วนใหญ่มักทำผิด

ทุกอย่างทำงานในเบราว์เซอร์ของคุณ ไม่ต้องมีบัญชี ไม่ต้องอัปโหลด และเราไม่เก็บสำเนาร่างข้อความของคุณไว้ที่ฝั่งเรา ข้อความที่คุณวางจะอยู่แค่ในหน้าที่คุณกำลังอ่านเท่านั้น

0 ตัวอักษร0 โพสต์280 ต่อโพสต์บน X (Twitter)

แพลตฟอร์ม

ลิงก์ถูกคิดน้ำหนักที่ 23 ตัวอักษรต่อลิงก์ ตามวิธีที่ X คิดค่าลิงก์

คำนำหน้านี้ใช้ตัวอักษรเหมือนข้อความอื่น ๆ ดังนั้นมันจะถูกกันไว้ก่อนแบ่งเธรด โพสต์เดียวจะไม่ถูกเรียงเลข

เธรดของคุณสำหรับ X (Twitter)

วางฉบับร่างของคุณด้านบน แล้วมันจะปรากฏที่นี่เป็นโพสต์ที่เรียงเลข แต่ละอันเต็มไปด้วยประโยคที่สมบูรณ์และวัดตามขีดจำกัด 280 ตัวอักษรที่ X (Twitter) อนุญาต ไม่มีอะไรถูกอัปโหลดและไม่มีอะไรถูกจัดเก็บ

จุดตัดจะตกที่ขอบเขตประโยค และจุดตัดย่อหน้าในฉบับร่างของคุณจะถูกให้ความสำคัญมากกว่าจุดตัดประโยค

ขีดจำกัดบน X และ Threads

ทั้งสองแพลตฟอร์มจำกัดความยาวของโพสต์เดียว และคาดหวังให้เนื้อหาที่ยาวกว่านั้นกลายเป็นเธรด ความแตกต่างอยู่ที่วิธีคิดค่าตัวอักษร X เขียนลิงก์ใหม่และคิดอัตราคงที่สำหรับลิงก์เหล่านั้น ส่วน Threads คิดทุกตัวอักษรของ URL ตามที่เขียนจริง

แพลตฟอร์มระดับขีดจำกัดต่อโพสต์ความหมายในเธรด
X (Twitter)บัญชีมาตรฐาน280 ตัวอักษรลิงก์ทุกลิงก์ถูกนับเป็น 23 ตัวอักษรไม่ว่าความยาวจริงจะเป็นเท่าใด
X (Twitter)บัญชี Premium25,000 ตัวอักษรโพสต์มาตรฐานจะไม่ถูกย่อเลย โพสต์ Premium ที่ยาวเกิน 280 ตัวอักษรจะถูกย่อไว้หลังปุ่ม "แสดงเพิ่มเติม" บนไทม์ไลน์
Threadsทุกบัญชี500 ตัวอักษรแต่ละโพสต์ในชุดข้อความได้รับโควตา 500 ตัวอักษรของตัวเอง ดังนั้นความคิดที่ยาวกว่านั้นจึงถูกแบ่งออกเป็นการตอบกลับหลายโพสต์แทนที่จะยัดลงในโพสต์เดียว

ขีดจำกัดตรวจสอบล่าสุดเมื่อ 2026-07-31. Threads ไม่มีบล็อกแฮชแท็กแบบดั้งเดิม โพสต์หนึ่งมีแท็กหัวข้อได้เพียงแท็กเดียว และข้อความของแท็กนั้นจะถูกนับรวมอยู่ใน 500 ตัวอักษรเดียวกัน

รูปแบบการเรียงเลขเธรด

การเรียงเลขเป็นสัญญาณบอกผู้อ่าน ไม่ใช่แค่พิธีการ มันบอกคนอ่านว่าเหลืออีกเท่าไรก่อนที่พวกเขาจะตัดสินใจว่าจะเริ่มอ่านหรือไม่ นอกจากนี้มันยังเป็นข้อความธรรมดา ดังนั้นไม่ว่าคุณจะเลือกรูปแบบใด ก็ยังถูกนับรวมในขีดจำกัดเดียวกับประโยคของคุณ

ไม่เรียงเลข

เมื่อแต่ละโพสต์ต้องยืนได้ด้วยตัวเอง เช่น หากคุณคาดว่าโพสต์แต่ละอันจะถูกแชร์ต่อโดยไม่มีบริบท คุณจะสูญเสียสัญญาณบอกผู้อ่านนี้ไป

ต้นทุนนี้เล็กน้อยแต่ต้องจ่ายในทุกโพสต์ บน X คำนำหน้า "12/14 " กินไป 6 ตัวอักษรในทั้ง 14 โพสต์ นั่นคือ 84 ตัวอักษรของทั้งเธรดที่หายไป เครื่องมือแบ่งเธรดคำนวณส่วนที่ต้องกันไว้นี้ก่อนแพ็กเนื้อหา และจะไม่เรียงเลขเลยเมื่อข้อความของคุณพอดีในโพสต์เดียว

เขียนเธรดที่ทำให้คนอ่านจนจบ

  • เขียนโพสต์แรกเป็นลำดับสุดท้าย นี่คือโพสต์เดียวที่คนส่วนใหญ่เห็นในฟีด จึงต้องทำหน้าที่เป็นข้อความที่สมบูรณ์ในตัวเอง ไม่ใช่ครึ่งแรกของประโยค
  • เว้นบรรทัดว่างระหว่างย่อหน้าก่อนวาง เครื่องมือแบ่งเธรดถือว่าการขึ้นย่อหน้าใหม่เป็นสัญญาณที่ชัดเจน และจะเริ่มโพสต์ใหม่ตรงนั้นทุกครั้งที่ประโยคถัดไปไม่พอดี
  • ทำให้เธรดสั้นพอที่จะอ่านจบ ห้าถึงสิบโพสต์คือช่วงที่เธรดส่วนใหญ่รักษาความสนใจไว้ได้ เกินสิบห้าโพสต์อัตราการอ่านจบจะลดลงอย่างรวดเร็วและแทบไม่มีใครอ่านโพสต์ท้าย ๆ เลย
  • การใส่ลำดับเลขไม่ได้ฟรี บน X คำนำหน้าอย่าง "12/14 " กินไป 6 ตัวอักษรจาก 280 ตัวอักษรของคุณในทุกโพสต์ ดังนั้นให้เปลี่ยนเป็น "1/ " หรือปิดการใส่ลำดับเลขถ้าเธรดกำลังจะไม่พอดี
  • ใส่ลิงก์ในโพสต์สุดท้าย ไม่ใช่โพสต์แรก URL หนึ่งลิงก์กิน 23 ตัวอักษรบน X ไม่ว่าจะอยู่ตรงไหน และลิงก์ในโพสต์แรกจะทำให้คนมีที่ไปก่อนที่พวกเขาจะได้อ่านอะไรเลย
  • อ่านผลการแบ่งก่อนเผยแพร่ เครื่องมือจะตัดตามประโยค แต่มีเพียงคุณเท่านั้นที่รู้ว่าประโยคไหนคือจุดไคลแมกซ์ที่ควรมีโพสต์เป็นของตัวเอง

คำถามที่พบบ่อย

การใส่ลำดับเลขนับรวมในขีดจำกัดตัวอักษรหรือไม่

นับ คำนำหน้าอย่าง "3/12 " เป็นข้อความธรรมดาสำหรับ X และ Threads ดังนั้นมันจึงกินตัวอักษรเหมือนเนื้อหาอื่น ๆ เครื่องมือแบ่งเธรดนี้จะกันที่ไว้สำหรับคำนำหน้าที่ยาวที่สุดในเธรดก่อนจัดเรียง แล้วจัดเรียงใหม่หากการเพิ่มตัวเลขทำให้จำนวนโพสต์ที่ต้องใช้เปลี่ยนไป

ลิงก์ถูกนับอย่างไรบน X

ทุก URL จะถูกเขียนใหม่ผ่าน t.co และนับเป็น 23 ตัวอักษรคงที่ ไม่ว่าลิงก์เดิมจะยาวแค่ไหน เครื่องมือแบ่งเธรดใช้การคำนวณนี้เมื่อคุณเลือก X ดังนั้นโพสต์ที่มี URL ติดตามผลยาว 180 ตัวอักษรจะถูกวัดตามวิธีที่ X วัด ไม่ใช่ตามวิธีที่โปรแกรมแก้ไขข้อความของคุณวัด

ข้อความของฉันถูกอัปโหลดหรือเก็บไว้ที่ไหนหรือไม่

ไม่ การแบ่งเธรดเกิดขึ้นในเบราว์เซอร์ของคุณด้วย JavaScript ไม่มีอะไรถูกส่งไปยังเซิร์ฟเวอร์ และไม่มีอะไรถูกบันทึกไว้ ปิดแท็บแล้วร่างข้อความก็หายไป

เธรดหนึ่งควรมีกี่โพสต์

ห้าถึงสิบโพสต์สำหรับหัวข้อส่วนใหญ่ นั่นยาวพอที่จะขยายความคิดหนึ่งเรื่องและสั้นพอที่คนจะอ่านจนจบ ถ้าร่างข้อความของคุณถูกแบ่งออกเป็นยี่สิบห้าโพสต์ วิธีแก้ที่ตรงไปตรงมามักจะเป็นการเผยแพร่เป็นบทความแล้วใช้เธรดสั้น ๆ เพื่อชวนให้คลิก

เครื่องมือแบ่งเธรดตัดข้อความตรงไหน

ตัดตามขอบเขตประโยคก่อน และให้ความสำคัญกับขอบเขตย่อหน้ามากกว่าขอบเขตประโยค ประโยคจะถูกตัดก็ต่อเมื่อยาวกว่าหนึ่งโพสต์เต็ม ๆ เท่านั้น และเมื่อนั้นมันจะตัดตรงช่องว่างแทนที่จะตัดกลางคำ อีโมจิและธงชาติจะไม่ถูกตัดครึ่งเด็ดขาด

ฉันสามารถใช้ร่างข้อความเดียวกันสำหรับ X และ Threads ได้หรือไม่

ได้ แต่ให้สลับปุ่มเลือกแพลตฟอร์มและตรวจสอบทั้งสองแบบ Threads ให้คุณ 500 ตัวอักษรต่อโพสต์เทียบกับ 280 บน X ดังนั้นข้อความเดียวกันมักจะกลายเป็นจำนวนโพสต์ที่น้อยลงประมาณครึ่งหนึ่ง และจุดตัดจะตกอยู่คนละตำแหน่ง
