QR Code Generator

I-paste ang isang link at kumuha ng QR code na puwede mong i-print. PNG para sa mga slide, SVG para sa anumang pupunta sa printer, at ang buong bagay ay naka-encode sa browser mo: walang ina-upload at walang binibilang na scan.

Huling na-update: 2026-08-06

Ang QR code ang pinakamaikling ruta mula sa isang bagay na pisikal papunta sa isang bagay na online. Pinapalitan nito ang isang shop window, isang tasa ng kape, isang table tent, isang booth banner, o ang huling slide ng isang talk sa isang tap. Para sa isang social team, kadalasang isang partikular na trabaho ang ginagawa nito: dinadala nito ang isang tao mula sa bagay na nasa harap nila papunta sa mga profile mo o sa booking link mo nang hindi hinihiling na i-type nila ang isang handle na baka mali ang spelling.

Ini-encode ng isang ito ang kahit anong text na i-paste mo, hanggang 213 byte, na kumportableng kasya sa anumang URL na malamang na i-print mo. Gumagamit ito ng error correction level M, ang gitnang setting, na nagpapahintulot sa isang scanner na ma-recover ang isang symbol na may humigit-kumulang 15 percent ng lugar nito na nasira: sapat para sa isang gasgas sa isang sticker o isang tiklop sa isang flyer. I-download ito bilang PNG sa 512, 1024, o 2048 pixel para sa mga slide at social post, o bilang SVG kapag pupunta ito sa printer at kailangang manatiling matalas sa anumang sukat.

Ituro ito sa isang page na kontrolado mo sa halip na sa iisang profile lang. Kapag na-print na ang isang code sa isang libong coaster, permanente nang naka-fix ang pattern, at ang tanging puwede mo pang baguhin ay kung ano ang nasa dulo ng link. Ang link-in-bio page ang karaniwang sagot: isang URL sa print run, at sa likod nito ay isang page na puwede mong ituro sa isang bagong launch, isang bagong booking form, o isang bagong profile kailanman mo gusto.

Ang hindi ginagawa ng tool na ito ay ang panonood kaninuman. Walang redirect sa pamamagitan ng mga server namin, walang scan counter, walang account step, at ang link na i-type mo ay hindi kailanman ipinapadala kahit saan. Ang encoder ay isang plain function na tumatakbo sa tab mo, na nangangahulugan din na patuloy na gumagana ang code kahit mawala ang page na ito bukas.

Sinusukat sa UTF-8 na byte, na siya talagang kaya ng simbolo. Ang mga plain URL ay nagkakahalaga ng isang byte kada character, ang mga accented at non-Latin na character ay nagkakahalaga ng dalawa o higit pa.

Ang PNG ay ang sukat na pinili mo, na may pattern na iginuhit sa buong pixel kaya walang module na magiging mas malapad ng kahit kaunti kaysa sa kapitbahay nito. Ang SVG ay vector, kaya kunin ang isang iyon para sa print. Kapwa may dalang apat na module na quiet zone at isang solidong puting background.

Isang tapos na code, para sa sukat

Na-encode ito noong ginawa ang pahina, ng parehong function na pinapatakbo ng tool sa itaas. Isa itong tunay na code, hindi isang screenshot: itutok ang camera sa monitor mo at bubuksan nito ang link.

Paano talaga gumagana ang isang QR code

Sulit ang dalawang minuto, dahil halos bawat nabigong print run ay bumabalik sa isa sa apat na bagay na ito.

  1. 1. Module, hindi pixel

    Ang bawat maliit na kwadrado ay isang module, at ang grid ay palaging apat na beses ang version number kasama ang 17 module kada gilid. Ang pinakamaliit na simbolo, version 1, ay 21 na module ang lapad; ang pinakamalaki na inaalok dito, version 10, ay 57. Ang mas maraming text ay nangangahulugan ng mas maraming module sa parehong nakalimbag na kwadrado, kaya ang mas mahabang link ay hindi lang mas malaking datos, ito ay pisikal na mas pinong detalye na kailangang resolbahin ng isang camera.

  2. 2. Ang mga pattern na hindi datos

    Ang tatlong malaking kwadrado sa mga sulok ay mga finder pattern: sinasabihan nila ang isang scanner kung saan ang code, alin ang taas nito, at kung gaano ito baluktot, kaya nababasa ang isang code sa isang anggulo o patiwarik. Ang tuldok na linya sa pagitan nila ay ang timing pattern, na nagtatakda ng module grid, at ang mas maliliit na kwadrado sa loob ng mas malalaking version ay mga alignment pattern na nagwawasto para sa isang baluktot o gusot na ibabaw. Wala sa mga ito ang link mo. Takpan ang isang kwadrado sa sulok at titigil ang code sa pagiging mahahanap, gaano man kahusay ang error correction.

  3. 3. Ang quiet zone

    Hinihiling ng standard ang 4 na module ng blangkong margin sa buong palibot. Bahagi ito ng code, hindi padding sa paligid nito: kung wala ang malinaw na hangganang iyon, hindi masasabi ng scanner kung saan natatapos ang simbolo at nagsisimula ang disenyo. Kasama ito sa parehong download dito, at ang pinakakaraniwang paraan para masira ang isang perpektong magandang code ay ang pag-crop nito o ang pagpapahintulot na dumaan ang isang larawan, border, o may kulay na panel hanggang mismo sa pattern.

  4. 4. Error correction

    Nagdadala ang isang QR code ng sparang kopya ng sarili nitong datos gamit ang Reed-Solomon coding, kaya nade-decode pa rin ang isang sirang, marumi, o bahagyang natatakpan na simbolo. May apat na level, at ang level ay isang kapalit: mas maraming recovery ay nangangahulugan ng mas maraming module para sa parehong link. Ginagamit ng tool na ito ang level M sa lahat ng oras.

Gaano karami ang kasya, bawat version

Pinipili ng tool ang pinakamaliit na version na kasya ang text mo, kaya ang isang maikling link ay gumagawa ng maliit, magaspang, at madaling i-scan na code. Ang mga kapasidad sa ibaba ay byte mode sa level M, na siyang ginagamit ng generator na ito, at ang ceiling ay 213 na byte.

Pag-print ng code na talagang gumagana sa pag-scan

  • Panatilihin ang quiet zone. Kailangan ng isang QR code ng malinis na margin na mga apat na module sa bawat gilid para masabi ng scanner kung saan natatapos ang symbol. Kasama na ito sa parehong download, kaya ilagay ang file kung ano ito sa halip na i-crop nang masikip sa pattern o hayaang tumagos ang isang background na larawan sa gilid.
  • Madilim sa maliwanag, hindi kailanman kabaliktaran. Karamihan ng scanner ay umaasang madilim na module sa maliwanag na background, at ang maliwanag na code sa isang madilim na larawan, gradient, o abalang imahe ang pinakakaraniwang dahilan kung bakit nabibigo ang isang naka-print na code. Ligtas na pagpipilian ang solid white sa likod ng puting-itim, at wala kang gagastusin dito.
  • I-print ito nang hindi bababa sa 2 cm ang lapad, na humigit-kumulang 0.8 inch. Isang magaspang na patakaran para sa anumang mas malayo: maglaan ng humigit-kumulang 1 cm ng code para sa bawat 10 cm ng distansya ng pag-scan, kaya ang isang poster na babasahin mula sa dalawang metro ay nangangailangan ng code na mga 20 cm ang lapad.
  • Mag-test scan bago ang print run, hindi pagkatapos. Buksan ang plain camera app sa dalawang telepono, isang bago at isang luma, at subukan ito mula sa distansyang totoong tatayuan ng mga tao, sa liwanag kung saan talagang mabubuhay ang code. Ang code na gumagana sa desk mo sa 10 cm ay puwedeng mabigo sa isang pader sa 2 metro.
  • Ang maiikling link ay gumagawa ng mas magaan na code. Ang isang 25 character na URL ay kasya sa isang version 2 na symbol na may 25 module kada gilid, habang ang isang 120 character na tracking URL ay nangangailangan ng version 7 sa 45 module kada gilid, kaya mas maliit ang bawat module at mas mahirap basahin ang code sa parehong nakaprint na lapad. Alisin ang mga campaign parameter, o gumamit ng short link.
  • Bigyan ang code ng masasabi. Ang isang blangkong parisukat ay binabalewala. Ang isang linya sa ilalim nito, na nagsasabi sa mga tao kung ano ang makukuha nila sa pag-scan, ay mas mahalaga kaysa sa anumang styling: "Scan for the menu" o "Scan to book" ay mananalo laban sa isang code na nakatayo mag-isa.

Mga madalas itanong

Nag-e-expire ba ang isang QR code?

Hindi. Ang isang QR code ay hindi isang record na naka-imbak sa isang server sa kung saan-saan, ito ang text mo na direktang naka-encode sa pattern ng itim at puting parisukat. Walang kailangang manatiling online para patuloy na gumana ang code, walang account na kailangang manatiling active, at hindi ito puwedeng i-off. Walang expiry ang mga code na ginawa dito dahil walang mag-e-expire.

Puwede ko bang palitan ang link matapos i-print ang code?

Hindi ang code mismo: naka-bake ang destinasyon sa pattern, kaya ang pagpalit nito ay mangangahulugang mag-print ng bago. Ang puwede mong palitan ay kung saan patutungo ang URL na iyon, kung sa iyo ang URL. Ituro ang code sa link-in-bio page mo at puwede mong ituro ang page na iyon sa isang bagong alok, isang bagong form, o isang bagong profile kasing dalas ng gusto mo habang valid pa rin ang naka-print na code. Iyan ang dahilan para maglaan ng saglit sa destinasyon bago ka mag-print ng isang libo ng anuman.

Puwede ko bang ilagay ang logo ko sa gitna ng code?

Hindi sa bersyong ito, at ang dahilan ay isang pangako itong hindi namin kayang panatilihin para sa bawat code. Nire-recover ng level M error correction ang humigit-kumulang 15 percent ng nasirang symbol, kaya madalas nabubuhay ang isang maliit na logo, pero depende ito sa sukat ng logo, kung saan ito nahuhulog, at kung aling mga module ang natatakpan nito. Mas gusto naming huwag bigyan ka ng control na tahimik na gumagawa ng mga code na nabibigo sa tanging telepono na hindi mo na-test. Ilagay na lang ang logo sa tabi ng code, sa isang caption o frame, kung saan nagagawa nito ang trabaho ng branding nang hindi kumakain ng data.

Dapat ko bang i-download ang PNG o ang SVG?

PNG kung ang code ay pupunta sa isang slide, social post, o email, kung saan ang fixed na pixel size ang inaasahan ng lahat. SVG kung pupunta ito sa printer o sa isang design file: vector ito, kaya nananatiling perpektong matalas sa anumang sukat, mula sa business card hanggang trade show banner, at maliit lang na bahagi ng laki ng file. Kapag nag-aalangan ka para sa print, kunin ang SVG.

Ipinapadala ba ang link ko sa mga server ninyo?

Hindi. Ang encoder ay tumatakbo nang buo sa browser mo: ang text mo ay nagiging grid ng mga module sa tab, ang preview ay iginuhit mula sa grid na iyon, at ang PNG ay na-rasterize sa mismong device mo. Walang ina-upload, walang naka-imbak, at walang redirect sa gitna ng link, kaya hindi namin nakikita kahit isang scan. Ibig sabihin din nito na hindi namin masasabi sa iyo kung ilang tao ang nag-scan nito, na siyang tapat na kapalit ng hindi pagsubaybay kaninuman.

Gaano kahaba ang puwedeng gawing link?

Hanggang 213 byte ng UTF-8, na siyang kapasidad ng pinakamalaking symbol na inaalok dito, ang version 10 sa error correction level M. Halos lahat ng URL ay kasya, kasama ang mahahaba na may mga campaign parameter. Ang mga accented at non-Latin na character ay mas mahal kaysa isang byte bawat isa, kaya ang counter sa page ay sumusukat ng byte sa halip na character, at ipinapakita nito kung aling version ang napili ng text mo habang nagta-type ka.

Bigyan ang code ng isang lugar na sulit puntahan

Permanente ang pattern, hindi kailangang maging permanente ang destinasyon. Itutok ang code sa isang Postify Link page at makakakuha ka ng isang URL na ipi-print, may bawat profile, alok, at booking link sa likod nito, na maaaring i-edit matagal pagkatapos nakadikit na ang mga sticker sa mga kahon.
