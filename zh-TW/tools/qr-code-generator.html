QR Code生成器

貼上一個連結，就能得到一個可以列印的QR Code。幻燈片用 PNG，送去印刷用 SVG，整個過程都在你的瀏覽器裡完成編碼：不上傳任何內容，也不統計任何掃描次數。

最後更新： 2026-08-06

QR Code是從實物通往線上最短的路徑。它能把一個櫥窗、一個咖啡杯、一張桌卡、一個展位橫幅，或者一場演講的最後一頁幻燈片，變成一次輕點。對社交團隊來說，它通常只做一件具體的事：讓人從眼前的實物，直接到達你的個人檔案或預約連結，而不用讓他們手動輸入一個很容易拼錯的帳號名。

這個工具會把你貼上的任意文本編碼進去，最多 213 位元組，足夠容納任何你可能會列印的連結。它使用糾錯級別 M，也就是中等檔位，能讓掃描器在符號大約 15% 的面積受損時依然識別出來：足以應對貼紙上的一處劃痕，或者傳單上的一道摺痕。適合幻燈片和社交貼文的場景，可以下載 512、1024 或 2048 畫素的 PNG，如果是要送去印刷、需要在任何尺寸下都保持清晰，則下載 SVG。

讓QR Code指向一個你自己能控制的頁面，而不是某個單一的個人檔案。一旦這個碼被印在一千個杯墊上，圖案就永遠固定了，你唯一還能改的，是連結另一端指向的內容。簡介連結頁通常是最好的答案：印刷品上只放一個 URL，而它背後的那個頁面，你隨時可以重新指向新的發布、新的預約表單或新的個人檔案。

這個工具不會做的一件事，是監視任何人。沒有經過我們伺服器的重定向，沒有掃描計數器，沒有註冊步驟，你輸入的連結也不會被發送到任何地方。這個編碼器就是執行在你標籤頁裡的一個普通函式，這也意味著，就算這個頁面明天消失了，這個碼依然能正常使用。

0 / 213 位元組一旦輸入文本，版本會自動確定

以 UTF-8 位元組計算，這也是符號實際容納的內容。純英文網址每個字元佔用 1 位元組，帶重音符號或非拉丁字元則佔用 2 位元組或更多。

PNG 是你選擇的尺寸，圖案被繪製在整數畫素上，所以不會出現某個模組比相鄰模組寬出一絲一毫的情況。SVG 是向量格式，印刷請選擇這個版本。兩者都帶有四個模組寬的靜區和純白背景。

預覽

你的 QR Code 會隨著輸入即時顯示在這裡。它是在這個標籤頁裡生成的，所以連結不會傳到我們的伺服器，也不會產生任何掃描記錄。

這一個是頁面構建時編碼生成的，使用的正是上方工具執行的同一個函式。它是一個真實的 QR Code，不是截圖： 用手機攝像頭對準你的螢幕，它就會開啟對應的連結。

QR Code 到底是如何工作的

值得花兩分鐘瞭解，因為幾乎每一次印刷失敗，追根究底都出在下面這四件事裡的某一件上。

  1. 1. 是模組，不是畫素

    每一個小方格叫做一個模組，網格邊長永遠等於版本號的四倍再加 17 個模組。最小的符號，也就是版本 1，邊長是 21 個模組；這裡提供的最大版本，版本 10，邊長是 57。文本越長，同樣的印刷尺寸裡就要塞進越多模組，所以更長的連結不只是資料更多，對攝像頭來說也是物理上更精細、更難識別的細節。

  2. 2. 那些不是資料的圖案

    四角中的三個大方塊是定點陣圖案： 它們告訴掃描器 QR Code 在哪裡、哪面朝上，以及傾斜了多少，這也是為什麼 QR Code 在傾斜或倒置時依然能被識別。它們之間的虛線是定位線，用於確定模組網格；較大版本內部的小方塊則是校正圖案，用於修正彎曲或褶皺的表面。這些圖案都不攜帶你的連結資訊。哪怕只擋住一個角上的方塊，QR Code 都會徹底無法被找到，無論糾錯等級多高都無濟於事。

  3. 3. 靜區

    標準要求四週留出 4 個模組寬的空白邊距。它是 QR Code 的一部分，不是可有可無的裝飾： 沒有這圈清晰的邊界，掃描器就無法判斷符號從哪裡結束、設計元素從哪裡開始。本頁的兩種下載版本都包含這圈靜區，而毀掉一個原本完好的 QR Code，最常見的方式就是把它裁掉，或者讓照片、邊框、彩色色塊緊貼圖案邊緣。

  4. 4. 糾錯能力

    QR Code 使用裡德-所羅門編碼，攜帶自身資料的備份副本，所以即使符號受損、髒汙或被部分遮擋，依然可以被解碼。糾錯能力共有四個等級，而等級本身是一種權衡： 恢復能力越強，同一條連結需要的模組就越多。這個工具全程使用 M 級。

糾錯等級，以及每一級能修復多大程度的損壞
等級可修復能換來什麼
L，低約 7%在相同連結下網格最小，也最不耐損耗。用在螢幕上沒問題，但用在會被反覆經手的物品上就顯得單薄。
M，中約 15%本工具所使用的等級。它能扛住貼紙上的劃痕或宣傳單上的摺痕，同時把網格保持得足夠粗，能在較小的印刷尺寸下正常掃描。
Q，四分位數約 25%代價是更密的網格，所以在相同的印刷寬度下，每個模組都會隨之變小。主要在 QR Code 的一部分會被遮擋時才值得選用。
H，高約 30%徽標疊加圖層所依賴的等級。它會把同一條連結變成密集得多的符號，而這正是人們在並排比較兩個 QR Code 時最容易忽略的代價。

M 是最適合印刷類行銷物料的等級。它能吸收貼紙、杯墊或摺疊宣傳單所經受的磨損，同時把網格保持得足夠粗，足以承受小尺寸印刷或遠距離掃描。L 級對於一件實體物品來說過於單薄，而 Q 級和 H 級換來的恢復能力大多數時候用不上，代價卻是在相同印刷寬度下讓每個模組都變得更小。

列印一個真正能被掃描的 QR Code

  • 保留空白邊距。QR Code每一邊都需要大約四個模組寬的清晰邊距，掃描器才能判斷符號的邊界在哪裡。兩種下載格式都已經包含了這個邊距，所以按原樣放置檔案就好，不要貼著圖案裁得太緊，也不要讓背景照片延伸到邊緣。
  • 深色圖案配淺色背景，絕不要反過來。大多數掃描器預設深色模組出現在淺色背景上，把淺色的碼放在深色照片、漸變色或雜亂圖片上面，是印刷出來的碼失效最常見的原因。純黑配純白，是最安全的選擇，而且不會讓你付出任何代價。
  • 列印時至少要保證QR Code寬度達到 2 釐米，大約是 0.8 英寸。對更遠距離的一個粗略經驗法則：每 10 釐米的掃描距離，大約需要 1 釐米的碼寬，所以在兩米外閱讀的海報，需要一個大約 20 釐米寬的碼。
  • 在正式印刷之前先測試掃描，而不是印完之後。用兩部手機的原生相機應用程式，一部新的，一部舊的，從人們實際會站立的距離，在這個碼將來實際所在的光線條件下試一試。一個在你桌上 10 釐米距離能掃出來的碼，貼到牆上 2 米之外可能就失效了。
  • 短連結能做出更簡潔的碼。一個 25 個字元的 URL，能放進每邊 25 個模組的版本 2 符號，而一個 120 個字元的追蹤連結，則需要每邊 45 個模組的版本 7，這意味著每個模組都更小，在同樣的列印寬度下會更難識別。去掉行銷活動引數，或者直接用短連結。
  • 給這個碼配一句話。一個光禿禿的方塊很容易被忽略。在它下面加一行字，告訴人們掃碼之後能得到什麼，這比任何裝飾都更有價值：「掃碼檢視選單」或「掃碼預約」，都比一個孤零零的碼更有效。

常見問題

QR Code會過期嗎？

不會。QR Code不是存在某個伺服器上的一條記錄，它是你的文本直接編碼進黑白方塊圖案裡的結果。不需要任何東西保持線上，這個碼就能繼續使用，也不需要任何帳號保持活躍，而且它無法被關閉。在這裡生成的碼沒有過期時間，因為根本沒有什麼東西可以過期。

碼印出來之後，還能改連結嗎？

碼本身不能改：目的地已經燒錄進圖案裡了，要改就得印一個新的。你能改的，是這個 URL 指向的內容，前提是這個 URL 屬於你。讓碼指向你的簡介連結頁，你就能在印出來的碼保持有效的同時，隨時把這個頁面重新指向新的優惠、新的表單或新的個人檔案。這也是為什麼在印一千份任何東西之前，值得花點時間想清楚目的地。

可以在碼中間放我的 logo 嗎？

目前這個版本還不支援，原因是這是一個我們沒辦法對每一個碼都保證做到的承諾。M 級糾錯能恢復大約 15% 受損的符號，所以一個小 logo 通常能保留下來，但能不能保留下來，取決於 logo 的大小、它落在什麼位置，以及它蓋住了哪些模組。我們不想給你一個會悄悄產生失效碼的功能，而恰好失效的又是你沒測試過的那一部手機。可以把 logo 放在碼旁邊，放進配文或邊框裡，這樣既能起到品牌作用，又不會佔用資料容量。

應該下載 PNG 還是 SVG？

如果這個碼要用在幻燈片、社交貼文或郵件裡，選 PNG，因為其他內容都預設使用固定畫素尺寸。如果要送去印刷，或者放進設計檔案，選 SVG：它是向量格式，從名片到展會橫幅，任何尺寸下都能保持完美清晰，而且檔案大小只是 PNG 的一小部分。如果不確定是不是要用於印刷，選 SVG 就對了。

我的連結會被發送到你們的伺服器嗎？

不會。編碼器完全在你的瀏覽器裡執行：你的文本在標籤頁裡變成一個模組網格，預覽圖是根據這個網格繪製的，PNG 也是在你自己的裝置上柵格化生成的。沒有任何內容會被上傳，沒有任何內容會被儲存，連結中間也沒有重定向，所以我們永遠看不到任何一次掃描。這也意味著我們無法告訴你有多少人掃過這個碼，這是不追蹤任何人所必須付出的誠實代價。

連結最長可以有多長？

最多 213 位元組的 UTF-8 文本，這是這裡提供的最大符號，也就是糾錯級別 M 的版本 10 的容量上限。幾乎任何 URL 都能放得下，包括帶行銷活動引數的長連結。帶重音符號的字元和非拉丁字元，每個都會佔用超過一個位元組，所以頁面上的計數器統計的是位元組數，而不是字元數，並會在你輸入時即時顯示當前文本對應的版本。

給這個 QR Code 一個值得跳轉的目的地

圖案是永久的，目的地卻不必是。把 QR Code 指向一個 Postify Link 頁面，你就能得到一個可以印刷的網址，背後連線著每一個個人檔案、優惠和預約連結，而且在貼紙貼上箱子之後依然可以隨時編輯。
