QRコード生成ツール

リンクを貼り付けるだけで、印刷できるQRコードが手に入ります。スライド用にはPNG、印刷用にはSVGを選べます。すべてブラウザ内でエンコードされるため、何もアップロードされず、スキャン回数が記録されることもありません。

最終更新日: 2026-08-06

QRコードは、目の前にある物理的なものからオンラインへとつながる最短ルートです。ショーウィンドウ、コーヒーカップ、テーブルの案内カード、ブースのバナー、プレゼンテーションの最後のスライドを、タップ一つで別の場所へつなげてくれます。ソーシャルチームにとっては、通常一つの明確な役割を果たします。目の前にいる人を、打ち間違えそうなアカウント名を入力させることなく、自社のプロフィールや予約リンクへと導くことです。

このツールは、貼り付けたテキストを最大213バイトまでエンコードできます。印刷する可能性のあるほとんどのURLには、余裕を持って対応できる容量です。誤り訂正レベルはMという中間設定を採用しており、シンボルの面積の約15パーセントが損傷していてもスキャナーが読み取れます。ステッカーのこすれや、チラシの折り目程度であれば十分にカバーできます。スライドやソーシャル投稿には512、1024、2048ピクセルのPNGでダウンロードでき、印刷用でどんなサイズでも鮮明さを保ちたい場合はSVGでダウンロードできます。

単一のプロフィールではなく、自分でコントロールできるページに向けましょう。コードが1000枚のコースターに印刷されてしまえば、そのパターンは永久に固定され、変更できるのはリンクの先にあるものだけです。link-in-bioページが定番の答えです。印刷物には1つのURLだけを載せておき、その先のページはいつでも新しいローンチや新しい予約フォーム、新しいプロフィールへと切り替えられます。

このツールがしないことは、誰かを監視することです。当社のサーバーを経由するリダイレクトも、スキャン回数のカウントも、アカウント登録のステップもなく、入力したリンクはどこにも送信されません。エンコーダーはブラウザのタブ内で動く単純な関数であり、つまり、このページが明日消えてしまっても、生成したコードはそのまま使い続けられるということです。

0 / 213バイトテキストが入力されるとバージョンが自動的に決まります

シンボルが実際に保持するUTF-8バイト数で計測しています。通常のURLは1文字につき1バイトですが、アクセント記号や非ラテン文字は2バイト以上になります。

PNGは選択したサイズで、パターンが整数ピクセルに描画されるため、隣より少し幅の広いモジュールが生じません。SVGはベクターなので、印刷にはこちらを選んでください。どちらも4モジュール分のクワイエットゾーンと白背景を含みます。

プレビュー

入力するとここにコードが表示されます。このタブ内で生成されるため、リンクがこちらに届くことはなく、スキャン数がカウントされることもありません。

ダウンロードする前に、スマートフォンのカメラでプレビューをスキャンしてみましょう。ここで読み取れれば、余白とコントラストを保つ限り紙でも読み取れます。

完成したコード(実寸)

これはページが構築された際に、上のツールと同じ関数でエンコードされたものです。スクリーンショットではなく本物のコードなので、モニターにカメラを向ければリンクが開きます。

QRコードの実際の仕組み

2分の価値はあります。失敗した印刷のほとんどは、この4つのいずれかが原因だからです。

  1. 1. モジュールであり、ピクセルではない

    1つ1つの小さな正方形はモジュールと呼ばれ、グリッドは常にバージョン番号の4倍に17モジュールを足した数になります。最小のシンボルであるバージョン1は1辺 21モジュールで、ここで用意している最大のバージョン 10は1辺57モジュールです。テキストが増えるほど同じ印刷サイズの中により多くのモジュールが詰め込まれるため、長いリンクは単にデータが増えるだけでなく、カメラが解読すべき物理的な細部が増えることを意味します。

  2. 2. データではないパターン

    四隅にある3つの大きな正方形はファインダーパターンで、スキャナーにコードの位置、向き、傾きを伝えます。これがコードが斜めや逆さまでも読み取れる理由です。その間にある点線はタイミングパターンでモジュールグリッドを決め、大きなバージョンの内側にある小さな正方形はアライメントパターンで、曲がったりしわが寄ったりした表面を補正します。これらはいずれもあなたのリンクではありません。角の正方形の1つを隠すと、誤り訂正の性能に関わらずコードはまったく見つけられなくなります。

  3. 3. クワイエットゾーン

    規格では、周囲全体に4モジュール分の余白を求めています。これは装飾ではなくコードの一部です。この明確な境界がなければ、スキャナーはシンボルがどこで終わりデザインがどこから始まるかを判別できません。ここでの両方のダウンロードにはこれが含まれており、正しく機能していたコードを壊す最も一般的な原因は、これを切り取ってしまうこと、あるいは写真や枠、色付きパネルをパターンぎりぎりまで配置してしまうことです。

  4. 4. 誤り訂正

    QRコードはリード・ソロモン符号を使って自身のデータの予備コピーを保持しているため、傷んだり、汚れたり、部分的に隠れたりしたシンボルでもデコードできます。レベルは4段階あり、そのレベルはトレードオフです。回復力が高いほど、同じリンクでもモジュール数が増えます。このツールでは常にレベルMを使用しています。

誤り訂正レベルと、それぞれが回復できる損傷の度合い
レベル回復できる割合それによって得られるもの
L(低)約7パーセント同じリンクに対して最小のグリッドですが、最も許容度が低いレベルです。画面上では問題ありませんが、扱われるものには心もとないです。
M(中)約15パーセントこのツールが使用しているレベルです。ステッカーの擦れやチラシの折り目には耐えつつ、小さく印刷してもスキャンできる程度の粗さを保ちます。
Q(準高)約25パーセントより密なグリッドと引き換えに得られ、各モジュールは同じ印刷幅の中で小さくなります。コードの一部が隠れる場合に主に価値があります。
H(高)約30パーセントロゴオーバーレイが依存するレベルです。同じリンクをはるかに密なシンボルに押し込みます。これは2つのコードを並べて比較するときに忘れられがちなコストです。

Mは印刷マーケティングに適したレベルです。ステッカーやコースター、折りたたまれたチラシが受ける摩耗を吸収しつつ、小さく印刷しても、離れた場所から読んでも耐えられる粗さのグリッドを保ちます。Lは物理的な物には心もとなく薄く、QとHはほとんど必要のない回復力と引き換えに、同じ印刷幅で各モジュールを小さくしてしまいます。

実際にスキャンできるコードを印刷するには

  • クワイエットゾーン(余白)を確保しましょう。QRコードは、スキャナーがシンボルの終わりを認識できるように、四方におよそ4モジュール分の余白が必要です。どちらのダウンロード形式にもすでに余白が含まれているため、パターンぎりぎりまでトリミングしたり、背景写真を端まで敷き詰めたりせず、そのまま配置してください。
  • 明るい背景に暗い模様が基本で、その逆は避けてください。ほとんどのスキャナーは、明るい背景に暗いモジュールが乗っている状態を想定しています。暗い写真やグラデーション、ごちゃごちゃした画像の上に明るいコードを重ねるのは、印刷したコードが読み取れなくなる最も多い原因です。純粋な黒に対して無地の白を背景にするのが安全な選択であり、コストもかかりません。
  • 少なくとも2センチメートル、およそ0.8インチの大きさで印刷してください。もっと離れた場所から読み取る場合の目安として、スキャン距離10センチメートルにつき、コードの幅を約1センチメートル確保してください。2メートル離れた場所から読み取るポスターであれば、コードの幅は約20センチメートルが必要です。
  • 印刷する前に、必ずテストスキャンを行ってください。新しいスマートフォンと古いスマートフォンの標準カメラアプリで、実際に人が立つであろう距離、実際にコードが置かれる照明の下で試してみましょう。デスク上で10センチメートルの距離ではうまくいっても、壁に貼って2メートル離れると読み取れなくなることがあります。
  • 短いリンクほど、軽いコードになります。25文字のURLであれば、1辺25モジュールのバージョン2シンボルに収まりますが、120文字のトラッキングURLでは1辺45モジュールのバージョン7が必要になり、同じ印刷サイズではモジュール一つ一つが小さくなって読み取りにくくなります。キャンペーンパラメータを取り除くか、短縮リンクを使いましょう。
  • コードに一言を添えましょう。何も説明のない四角形は無視されます。スキャンすると何が得られるかを伝える一文をコードの下に添えるだけで、どんな装飾よりも効果があります。「スキャンしてメニューを見る」や「スキャンして予約する」という一言があれば、コードだけがぽつんと置かれているよりもずっと機能します。

よくある質問

QRコードに有効期限はありますか。

いいえ。QRコードはどこかのサーバーに保存された記録ではなく、テキストそのものが白黒の模様として直接エンコードされたものです。コードが機能し続けるために何かをオンラインに残しておく必要はなく、アカウントを有効な状態に保つ必要もなく、誰かが停止させることもできません。ここで作成したコードには有効期限がありません。そもそも期限切れになるものが存在しないからです。

印刷した後にリンクを変更できますか。

コード自体は変更できません。リンク先はパターンの中に焼き込まれているため、変更するには新しいコードを印刷し直す必要があります。変更できるのは、そのURLが自分の管理下にある場合、URLの先が導く場所です。コードをlink-in-bioページに向けておけば、印刷したコードを有効なまま、そのページの先を新しいオファーや新しいフォーム、新しいプロフィールへと好きなだけ切り替えられます。だからこそ、何かを1000枚単位で印刷する前に、リンク先について少し考える価値があります。

コードの中央にロゴを入れることはできますか。

現在のバージョンではできません。理由は、すべてのコードに対してその安全性を保証できないからです。レベルMの誤り訂正はシンボルの約15パーセントの損傷を回復できるため、小さなロゴであれば残ることが多いのですが、それはロゴのサイズや位置、どのモジュールを覆うかによって変わります。テストしていない1台のスマートフォンでこっそり読み取れなくなるコードを生み出しかねない機能を、あえて提供したくありません。ロゴはコードの中に入れるのではなく、キャプションや枠の中など、コードの横に配置してください。データを消費することなく、ブランディングの役割を果たせます。

PNGとSVGのどちらをダウンロードすべきですか。

スライドやソーシャル投稿、メールに使う場合はPNGがおすすめです。周囲の要素が固定ピクセルサイズを前提としているためです。印刷用やデザインファイルに使う場合はSVGがおすすめです。ベクター形式なので、名刺から展示会用バナーまで、どんなサイズでも完全に鮮明さを保ち、ファイルサイズもわずかです。印刷用途で迷ったら、SVGを選んでください。

入力したリンクは、御社のサーバーに送信されますか。

いいえ。エンコーダーはすべてブラウザ内で完結します。入力したテキストはタブの中でモジュールの格子模様に変換され、そのグリッドからプレビューが描画され、PNGはお使いの端末上でラスタライズされます。何もアップロードされず、何も保存されず、リンクの途中にリダイレクトも存在しないため、私たちはスキャンを一件たりとも把握できません。つまり、何人がスキャンしたかをお伝えすることもできませんが、それは誰も追跡しないことと引き換えの、正直なトレードオフです。

リンクの長さはどこまで対応していますか。

UTF-8で最大213バイトまで対応しています。これは、このツールで生成できる最大のシンボルであるバージョン10、誤り訂正レベルMの容量です。キャンペーンパラメータが付いた長いURLも含め、実質的にほとんどのURLに対応できます。アクセント記号付きの文字や非ラテン文字は1文字あたり1バイトを超えて消費するため、ページ上のカウンターは文字数ではなくバイト数を測定しており、入力に応じて選択されているバージョンを表示します。

コードの行き先には価値のあるものを

パターンは固定ですが、行き先は固定である必要はありません。コードをPostify Linkページに向ければ、印刷用の1つのURLの裏にすべてのプロフィール、オファー、予約リンクをまとめられ、ステッカーを箱に貼った後でも編集し続けられます。
