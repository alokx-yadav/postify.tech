QR-Code-Generator

Füg einen Link ein und erhalte einen QR-Code zum Drucken. PNG für Präsentationen, SVG für alles, was zum Drucker geht, und das Ganze wird direkt in deinem Browser erstellt: nichts wird hochgeladen und kein Scan wird je gezählt.

Zuletzt aktualisiert: 2026-08-06

Ein QR-Code ist der kürzeste Weg von etwas Physischem zu etwas Digitalem. Er macht aus einem Schaufenster, einem Kaffeebecher, einem Tischaufsteller, einem Messestand-Banner oder der letzten Folie eines Vortrags einen Klick. Für ein Social-Team erledigt er meist eine ganz bestimmte Aufgabe: Er bringt jemanden von dem Objekt vor ihm zu deinen Profilen oder deinem Buchungslink, ohne dass er einen Handle eintippen muss, den er falsch schreiben würde.

Dieser Generator codiert jeden eingefügten Text, bis zu 213 Byte, was für jede URL, die du wahrscheinlich drucken willst, mehr als genug Platz bietet. Er nutzt Fehlerkorrekturstufe M, die mittlere Einstellung, die es einem Scanner erlaubt, ein Symbol mit etwa 15 Prozent beschädigter Fläche noch zu lesen: genug für einen Kratzer auf einem Aufkleber oder eine Falte in einem Flyer. Lade ihn als PNG in 512, 1024 oder 2048 Pixel für Präsentationen und Social-Posts herunter, oder als SVG, wenn er zum Drucker geht und bei jeder Größe scharf bleiben muss.

Richte ihn auf eine Seite, die du kontrollierst, statt auf ein einzelnes Profil. Sobald ein Code auf tausend Untersetzern gedruckt ist, steht das Muster für immer fest, und das Einzige, was du noch ändern kannst, ist das, was am anderen Ende des Links liegt. Eine Link-in-Bio-Seite ist die übliche Antwort: eine URL auf der Druckauflage, und dahinter eine Seite, die du jederzeit auf einen neuen Launch, ein neues Buchungsformular oder ein neues Profil umleiten kannst.

Was dieses Tool nicht tut, ist irgendjemanden zu beobachten. Es gibt keine Weiterleitung über unsere Server, keinen Scan-Zähler, keinen Konto-Schritt, und der Link, den du eintippst, wird nie irgendwohin gesendet. Der Encoder ist eine reine Funktion, die in deinem Tab läuft, was auch bedeutet, dass der Code weiter funktioniert, falls diese Seite morgen verschwindet.

Gemessen in UTF-8-Bytes, das ist es, was das Symbol tatsächlich fasst. Einfache URLs kosten ein Byte pro Zeichen, Zeichen mit Akzenten und nicht-lateinische Zeichen kosten zwei oder mehr.

Das PNG hat die von dir gewählte Größe, mit dem Muster auf ganzen Pixeln gezeichnet, damit kein Modul auch nur ein Haar breiter ist als sein Nachbar. Das SVG ist Vektorgrafik, nimm also das für den Druck. Beide tragen die vier Module breite Ruhezone und einen durchgehend weißen Hintergrund.

Dieser wurde beim Erstellen der Seite codiert, mit derselben Funktion, die das Tool oben ausführt. Es ist ein echter Code, kein Screenshot: Richte eine Kamera auf deinen Monitor, und sie öffnet den Link.

Wie ein QR-Code wirklich funktioniert

Zwei Minuten wert, denn fast jeder gescheiterte Druck lässt sich auf eines dieser vier Dinge zurückführen.

  1. 1. Module, keine Pixel

    Jedes kleine Quadrat ist ein Modul, und das Raster ist immer viermal die Versionsnummer plus 17 Module pro Seite. Das kleinste Symbol, Version 1, ist 21 Module breit; das größte hier angebotene, Version 10, ist 57. Mehr Text bedeutet mehr Module im selben gedruckten Quadrat, ein längerer Link ist also nicht nur mehr Daten, sondern physisch feinere Details, die eine Kamera auflösen muss.

  2. 2. Die Muster, die keine Daten sind

    Die drei großen Quadrate in den Ecken sind Suchmuster: Sie sagen einem Scanner, wo der Code ist, wie herum er liegt und wie schief er ist, deshalb lässt sich ein Code auch schräg oder auf dem Kopf lesen. Die gepunktete Linie dazwischen ist das Taktmuster, das das Modulraster festlegt, und die kleineren Quadrate innerhalb größerer Versionen sind Ausrichtungsmuster, die eine gewölbte oder zerknitterte Oberfläche ausgleichen. Nichts davon ist dein Link. Deck ein Eckquadrat ab, und der Code lässt sich überhaupt nicht mehr finden, egal wie gut die Fehlerkorrektur ist.

  3. 3. Die Ruhezone

    Der Standard verlangt 4 Module leeren Rand ringsherum. Das ist Teil des Codes, kein Polster darum: Ohne diesen klaren Rand kann ein Scanner nicht erkennen, wo das Symbol endet und das Design beginnt. Beide Downloads hier enthalten ihn, und der häufigste Weg, einen ansonsten perfekten Code kaputt zu machen, ist ihn wegzuschneiden oder ein Foto, einen Rahmen oder eine farbige Fläche direkt bis ans Muster reichen zu lassen.

  4. 4. Fehlerkorrektur

    Ein QR-Code trägt mit Reed-Solomon-Codierung Ersatzkopien seiner eigenen Daten, ein beschädigtes, verschmutztes oder teilweise verdecktes Symbol lässt sich also trotzdem decodieren. Es gibt vier Stufen, und die Stufe ist ein Kompromiss: mehr Wiederherstellung bedeutet mehr Module für denselben Link. Dieses Tool nutzt durchgehend Stufe M.

M ist die Stufe, die zu gedrucktem Marketing passt. Sie fängt die Abnutzung ab, die ein Aufkleber, ein Bierdeckel oder ein gefalteter Flyer mitbekommt, und hält das Raster grob genug, um klein gedruckt oder aus der Ferne gelesen zu werden. L ist dünner, als ein physisches Objekt verdient, und Q und H erkaufen eine Wiederherstellung, die du meist nicht brauchst, indem sie jedes Modul bei gleicher Druckbreite kleiner machen.

Wie viel passt hinein, Version für Version

Einen Code drucken, der wirklich scannt

  • Halte die Ruhezone ein. Ein QR-Code braucht einen freien Rand von etwa vier Modulen auf jeder Seite, damit ein Scanner erkennt, wo das Symbol endet. Beide Downloads enthalten sie bereits, platziere die Datei also so, wie sie ist, statt sie eng an das Muster heranzuschneiden oder ein Hintergrundfoto bis an den Rand laufen zu lassen.
  • Dunkel auf hell, nie umgekehrt. Die meisten Scanner erwarten dunkle Module auf hellem Hintergrund, und ein heller Code über einem dunklen Foto, einem Verlauf oder einem unruhigen Bild ist der häufigste Grund, warum ein gedruckter Code scheitert. Reines Weiß hinter reinem Schwarz ist die sichere Wahl, und sie kostet dich nichts.
  • Drucke ihn mindestens 2 cm breit, das sind etwa 0.8 Zoll. Eine grobe Faustregel für größere Entfernungen: rechne mit etwa 1 cm Code pro 10 cm Scan-Abstand, ein Poster, das aus zwei Metern gelesen wird, braucht also einen Code von etwa 20 cm Breite.
  • Teste den Scan vor der Druckauflage, nicht danach. Öffne die normale Kamera-App auf zwei Handys, einem neuen und einem alten, und probiere es aus der Entfernung, in der die Leute wirklich stehen werden, im Licht, in dem der Code wirklich hängen wird. Ein Code, der auf deinem Schreibtisch aus 10 cm funktioniert, kann an einer Wand aus 2 Metern versagen.
  • Kurze Links ergeben leichtere Codes. Eine URL mit 25 Zeichen passt in ein Version-2-Symbol mit 25 Modulen pro Seite, während eine 120 Zeichen lange Tracking-URL Version 7 mit 45 Modulen pro Seite braucht, jedes Modul wird also kleiner und der Code schwerer zu lesen bei derselben Druckbreite. Streich die Kampagnen-Parameter, oder nutze einen Kurzlink.
  • Gib dem Code etwas zu sagen. Ein nacktes Quadrat wird ignoriert. Eine Zeile darunter, die den Leuten sagt, was sie fürs Scannen bekommen, ist mehr wert als jedes Styling: "Scan für die Speisekarte" oder "Scan zum Buchen" schlägt einen Code, der allein dasteht.

Häufig gestellte Fragen

Läuft ein QR-Code ab?

Nein. Ein QR-Code ist keine Aufzeichnung, die irgendwo auf einem Server liegt, sondern dein Text, direkt in das Muster aus schwarzen und weißen Quadraten codiert. Nichts muss online bleiben, damit der Code weiter funktioniert, kein Konto muss aktiv bleiben, und er kann nicht abgeschaltet werden. Hier erstellte Codes haben kein Ablaufdatum, weil es nichts gibt, das ablaufen könnte.

Kann ich den Link ändern, nachdem der Code gedruckt ist?

Nicht den Code selbst: Das Ziel ist fest ins Muster eingebacken, eine Änderung bedeutet also, einen neuen zu drucken. Was du ändern kannst, ist, wohin diese URL führt, sofern die URL dir gehört. Richte den Code auf deine Link-in-Bio-Seite, und du kannst diese Seite so oft du willst auf ein neues Angebot, ein neues Formular oder ein neues Profil umleiten, während der gedruckte Code gültig bleibt. Das ist der Grund, dir vor dem Druck von tausend Exemplaren einen Moment Zeit für das Ziel zu nehmen.

Kann ich mein Logo in die Mitte des Codes setzen?

In dieser Version nicht, und der Grund ist, dass wir dieses Versprechen nicht für jeden Code halten können. Fehlerkorrekturstufe M gleicht etwa 15 Prozent eines beschädigten Symbols aus, ein kleines Logo übersteht das oft, aber ob es das tut, hängt von der Größe des Logos ab, von der Stelle, an der es liegt, und davon, welche Module es abdeckt. Wir geben dir lieber keine Funktion an die Hand, die still Codes erzeugt, die auf genau dem einen Handy scheitern, das du nicht getestet hast. Setz das Logo stattdessen neben den Code, in eine Bildunterschrift oder einen Rahmen, wo es die Branding-Aufgabe erledigt, ohne Daten zu fressen.

Soll ich das PNG oder die SVG herunterladen?

PNG, wenn der Code in eine Präsentation, einen Social-Post oder eine E-Mail geht, wo eine feste Pixelgröße das ist, was alles andere erwartet. SVG, wenn er zum Drucker geht oder in eine Design-Datei: Es ist ein Vektor, bleibt also bei jeder Größe perfekt scharf, von der Visitenkarte bis zum Messebanner, und die Dateigröße ist ein Bruchteil davon. Im Zweifel für den Druck: nimm die SVG.

Wird mein Link an eure Server gesendet?

Nein. Der Encoder läuft vollständig in deinem Browser: Dein Text wird im Tab zu einem Raster aus Modulen, die Vorschau wird aus diesem Raster gezeichnet, und das PNG wird auf deinem eigenen Gerät gerastert. Nichts wird hochgeladen, nichts wird gespeichert, und es gibt keine Weiterleitung mitten im Link, wir sehen also nie auch nur einen einzigen Scan. Das bedeutet auch, dass wir dir nicht sagen können, wie viele Leute gescannt haben, was der ehrliche Preis dafür ist, niemanden zu tracken.

Wie lang darf der Link sein?

Bis zu 213 Byte UTF-8, das ist die Kapazität des größten hier angebotenen Symbols, Version 10 bei Fehlerkorrekturstufe M. Praktisch jede URL passt hinein, auch lange mit Kampagnen-Parametern. Akzentzeichen und nicht lateinische Zeichen kosten mehr als ein Byte pro Zeichen, der Zähler auf der Seite misst also Byte statt Zeichen und zeigt dir beim Tippen, welche Version dein Text auswählt.

Gib dem Code ein Ziel, das sich lohnt

Das Muster ist dauerhaft, das Ziel muss es nicht sein. Richte den Code auf eine Postify-Link-Seite, und du bekommst eine URL zum Drucken, mit jedem Profil-, Angebots- und Buchungslink dahinter, bearbeitbar noch lange, nachdem die Aufkleber auf den Kartons kleben.
